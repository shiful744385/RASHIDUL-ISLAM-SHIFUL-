Security Commands

Powerful and easy-to-use commands to configure and control every security feature.

?r dashboard

Dashboard

Open the main security control panel

?r status

Status

Check current protection status of the server

?r setup

Setup

Quick setup wizard for first-time configuration

?r config

Config

Configure individual security modules and settings

?r config setting:anti_spam

Anti-Spam Toggle

Enable or disable anti-spam protection

?r config setting:nuke_limit

Nuke Limit

Set threshold for anti-nuke detection (e.g. 5)

?r lockdown

Lockdown

Instantly lock the server during an attack

?r backup

Backup

Create a full backup of roles & channels

?r restore

Restore

Restore server from a previous backup

?r whitelist

Whitelist

Add users/roles/bots to the trust list

?r logs

Logs

View recent security and moderation logs

?r help

Help

Show all available commands and usage
